Étape 1 — Mettre les images en ligne (une seule fois)

  1. Dans ton projet payesmart-69-main, ouvre le dossier public/.
  2. Crée à l'intérieur un dossier signature.
  3. Dépose-y les 5 fichiers fournis : imarra-logo.png, ic-phone.png, ic-mail.png, ic-web.png, ic-pin.png.
  4. Déploie ton site (le déploiement habituel de imarra.be).
  5. Vérifie dans un navigateur que cette adresse affiche bien le logo :
    https://imarra.be/signature/imarra-logo.png

Étape 2 — Installer dans Apple Mail

  1. Mail → menu Mail → Réglages… → onglet Signatures.
  2. Compte imarra → + pour créer la signature.
  3. Décoche « Toujours utiliser ma police de message par défaut ».
  4. Reviens ici, clique « Copier la signature », puis colle (Cmd + V) dans l'éditeur de Mail.

Comme les images sont sur imarra.be, elles s'affichent maintenant chez tous tes destinataires (Outlook, Gmail, etc.) et les liens restent cliquables.
